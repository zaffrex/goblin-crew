# 결정: QA Mia를 일본어가 모국어인 첫 플레이어로 설정한다

- 레벨: L3(진마씨)
- 날짜: 2026-11-21
- 결정자: 진마씨
- 참여: 진마씨(제안·결정), PM Noah(선택지 제시·기록)
- 출처: `#goblin-ceo` 2026-11-21 Mia 일본인 설정 상담 스레드 — 진마씨 "미아를 일본인으로 설정하는게 좋을까? 말하는것도 일본어로", "대사의 자연스러움이라든지 봐줄수 있지 않겠어? 지금 내가봐도 부자연스러웠거든" → PM 선택지 A/B/C → 진마씨 답 "A". 이슈 #608

## 배경
게임 안 대사는 일본어 전용이고([2026-11-17](2026-11-17-japanese-only.md)), Luna가 작가와 감수를 같이 맡는다([2026-11-18](2026-11-18-designer-ja-writer.md)). 쓴 사람이 자기 글을 감수해서 어색한 줄이 남고, 진마씨가 지금도 부자연스럽다고 느낀다. 이는 11/18 기록의 "다시 볼 조건"(감수를 따로 두는 쪽)에 해당한다. QA 역할 정의를 바꾸는 일이라 팀 운영 방식 변경(L3)으로 올렸다.

## 선택지
- A. Mia를 일본어 원어민 첫 플레이어로 설정. 진행 기록(think-aloud)은 일본어, 보고서에 "어색한 대사" 칸 추가. 보고서 나머지와 Slack은 한국어. 고치는 건 Luna (역할 신설 없음, 비용 거의 0 / Mia가 Sonnet이라 미묘한 말맛에 약할 수 있음)
- B. A에 더해 보고서와 Slack까지 전부 일본어 (진마씨 원안 그대로 / 팀 소통 한국어 규칙에 예외, 진마씨 보고서 읽기 부담 증가)
- C. 그대로 두고 원어민 검수는 공개 때 외부에 맡김 (지금 비용 0 / 그때까지 어색한 줄이 남고, 외부 검수는 유료라 L3)

## 결정
**A.** 진마씨 결정. PM 추천안과 같다.

효과는 "일본인" 설정 자체가 아니라 **쓴 사람(Luna)과 읽는 사람(Mia)이 다르다**는 데서 나온다. Mia는 대사를 게임 화면 안에서, 어느 장면에서 누구 입에서 나오는지까지 같이 처음 읽는 유일한 팀원이다. 적용 (`.claude/agents/qa.md`):
1. 정의 첫 줄: 일본어가 모국어인 첫 플레이어
2. 진행 기록은 일본어
3. 보고서 "어색한 대사" 칸: 원문 인용 / 누가·어떤 장면 / 왜 어색한지 / 자연스러운 예
4. 대사 파일은 찾지 않는다(대사가 힌트라 정답이 샌다). 화면에 실제로 나온 줄만 본다
5. 고치는 건 Luna. Mia의 "자연스러운 예"는 참고안

적용은 다음 Mia 실행(#603 화면 1 QA)부터다.

### 보충: Mia의 한국어 말투 (2026-11-21, 이슈 #627)
같은 스레드에서 진마씨 추가 지시: "슬랙은 한글로 하는데 좀 한국어가 어색한거 알지? 그런설정". 적용 (`.claude/agents/qa.md` "한국어 말투"):
- Slack과 보고서의 한국어 칸은 일본어 원어민이 쓰는 조금 서툰 한국어(조사 어긋남, 딱딱한 존댓말, 일본어 맞장구 가끔). Slack과 보고서 말투를 같게 한다(PM 판단, 진마씨께 Slack만으로 좁힐지 여쭤 둠)
- 서툰 건 말투만. 화면 id·클릭 수·재현 순서·인용 대사·이슈 번호 같은 사실은 정확하게(팀이 보고 고치므로)
- 외국인 말투를 희화화하지 않는다(발음 흉내·です 붙이기·일부러 틀린 맞춤법 금지)
- 맞장구는 괄호 없이 쓰고 「」는 화면 인용에만 쓴다. 어색한 대사의 이유 분류어는 네 가지 중 하나를 그대로 쓴다(Luna 감수 리뷰, PR #628)

## 반대 의견
PM이 올린 한계 두 가지: ① Mia도 Claude라서 설정만으로 일본어 실력이 오르지 않고, Sonnet이라 Luna(Opus)보다 말맛에 약할 수 있다. ② Mia는 플레이 중 실제로 나온 대사만 봐서 못 나온 실패 대사를 놓친다. 둘 다 "다시 볼 조건"으로 다룬다.
