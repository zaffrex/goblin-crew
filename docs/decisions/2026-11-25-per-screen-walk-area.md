# 결정: 화면 JSON `walkArea`로 화면별 걷기 영역을 둔다. 높은/바닥 대상 기준선은 공통 y 200 그대로

- 날짜: 2026-11-25

- 출처: #938, PR(이 기록과 같은 PR)

## 배경
걷기 영역이 모든 화면 공통 `WALK_AREA`(x 16~463, y 200~252, `src/core/config.ts`)였다. 빨래방 그림은 아래 벽 띠가 y 172~235이고 나무 바닥(woodL)이 y 236부터다(`art/scenes/laundromat.room.mjs` `FLOOR_Y`). 그래서 벽 띠를 누르면 발이 y 200~235, 벽 위에 서서 떠 보였다. 정답 길은 `floor`(y 244)·`reachPoint`로만 서서 테스트에서 안 걸렸다.

다른 두 화면은 바닥 위 끝이 공통 위 끝보다 위다: `magpie_nest` `FLOOR_TOP` 196, `park_fountain` `PATH_TOP` 198.

## 선택지
- A. 화면 JSON에 `walkArea`를 두고, 적은 키만 공통 값을 덮는다 (JSON 1줄 / 엔진 걷기 자르는 곳 전부가 화면 값을 따라야 함)
- B. 그림 바닥을 y 200까지 올린다 (엔진 0줄 / 세탁기·건조기·자판기를 다 다시 그림, PM 비추천)
- C. 공통 `WALK_AREA.top`을 236으로 올린다 (1줄 / 화면 1 시소 판 y 214·고리 releasePoint y 235가 영역 밖이 되어 검사가 깨짐)

## 결정
**A.**
1. `ScreenData.walkArea?: { left?, top?, right?, bottom? }`. 적은 키만 `WALK_AREA`를 덮는다(`walkAreaOf`). 공통 영역 **안으로 줄이기만** 한다. 넓히면 게이지 띠(y 256~) 등 다른 검토가 필요해서다. 검사 `walk-area`: 정수, 공통 범위 안, 비지 않음. 모르는 키는 `unknown-key`.
2. 걷기를 자르는 곳은 전부 화면 값을 쓴다: 바닥 탭, `move floor` 도착점, 비켜 서기(#825·#862) 후보 x 범위, 높은 대상 앞 내려서기 아래 끝, 처음 배치, `releasePoint`·`board` 검사, 터치 `あるく` 안내(5-2-6절)의 "영역 밖", 회색 배치 검사 양 끝.
3. **높은/바닥 대상 기준선은 화면 값을 안 따른다.** `HIGH_TARGET_LINE`(= 공통 위 끝 200)으로 이름을 따로 붙였다. 빨래방에서 236을 따라가면 아래 끝이 236인 `dryer_3`·`soap_vending`이 높은 대상(`<=`)이 되어, `stomp` 설 곳이 옆 → 가운데로 바뀌고 덕트 `stretch` 뒤 비켜 서기(설계 laundromat.md 2-2 E7)의 "낮은 대상"에서 `dryer_3`이 빠진다.
4. 빨래방만 `"walkArea": { "top": 244 }`. 다른 두 화면은 안 적는다.
   - 바닥 첫 줄(`FLOOR_Y` 236)이 아니라 **셔터 아래 끝**(`SHUTTER.y + h` = 244, `art/scenes/laundromat.shutter.mjs`)이다. 셔터가 이 화면에서 가장 앞으로 나온 바닥 물건이라서다. 236이면 셔터 앞(x 24~151)에서 발이 셔터 밑 레일보다 8px 위, 판 위에 떠 보이고, 셔터 밖 길바닥 열쇠(90,236 30×8)가 발보다 앞에 그려져 깊이가 뒤집혔다(Luna PR 리뷰).
   - 대가: 앞뒤 깊이가 244~252, 8px로 줄어든다(236이면 16px). 이 화면은 자리가 `floor`(y 244) 하나라 처음 배치·정답 길 모습은 안 바뀐다. 셔터 앞만 244로 두는 모양 있는 영역은 엔진 일이 커서 하지 않는다.

장대 도달: 엔진에는 거리 검사가 없다(`maxReach` 80은 설계 제안값). 설계 87줄 기준으로 손(발 위 32px) y 204~220에서 `reachPoint` y 150까지 54~70px라 80 안이다.

- 다음 화면을 그릴 때 바닥 위 끝이 200보다 낮으면 `walkArea.top`을 같이 적는다. 높은 물건 기준이 화면마다 달라야 하는 화면이 나오면 그때 따로 정한다.
