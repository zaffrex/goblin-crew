# 결정: 디자이너 Luna가 일본어 대사 작가·감수를 맡는다

- 날짜: 2026-11-18

- 참여: 진마씨(결정), PM Noah(선택지 제시·기록)

## 배경
게임 안 글을 전부 일본어로 바꾼 뒤([2026-11-17 결정](2026-11-17-japanese-only.md)) 재플레이에서 진마씨가 대사가 부자연스럽다고 짚었다. 특히 실패할 때 대사. PM이 63줄을 다시 읽어 보니 원인은 몇 줄이 아니라 만드는 방식이었다: 한국어 대사를 한 줄씩 옮겨 한국어 말투가 남았고, 실패 대사가 리액션 대신 원인을 설명했고, 원어민 검수가 없었다. 역할 정의를 바꾸는 일이라 팀 운영 방식 변경(L3)으로 올렸다.

## 선택지
- A. Luna 정의에 "일본어 대사 작가·감수" 책임과 절차를 추가 (비용 0, 바로 적용 / Luna 일이 늘어남)
- B. 일본어 전담 역할 신설 (대사만 보는 사람이 생김 / 대사 약 80줄에 비해 실행 수·비용·조율이 늘어남)
- C. 정의는 그대로, `ja-text.md` 규칙만 강화 (변경 최소 / 쓰는 방식이 안 바뀌어 같은 원인이 남음)

## 결정
**A.** 진마씨 결정. PM 추천안과 같다.

이름표만 바꾸면 같은 모델이라 일본어 실력 자체는 오르지 않는다. 그래서 **절차를 정의에 같이 넣었다** (`.claude/agents/designer.md` "일본어 대사 작가·감수" 절):
1. 한국어 초안 없이 장면 의도에서 바로 일본어로 쓴다
2. 캐릭터 말투표(1인칭, 어미, 반말/존댓말)를 `ja-text.md` 3절에 두고 지킨다
3. 실패 대사는 "리액션 → 자책/츳코미" 순서
4. 대사 PR마다 "소리 내 읽기" 자체 점검표를 붙인다

`CLAUDE.md` 팀 표의 디자이너 주 책임에도 적었다. 적용은 #359(대사 수정)부터다.

## 반대 의견
PM 우려: Luna가 퍼즐·아트·UI에 대사까지 맡아 일이 몰린다. 대응: UI 세부 전수 점검(#330) 쪽 확인·정리는 PM이 더 가져간다. 가장 강한 반론은 "설정만 바꿔서는 실력이 안 오른다"인데, 그래서 절차(위 1~4)를 같이 넣었고 효과는 진마씨가 다음 재플레이에서 판단한다.
