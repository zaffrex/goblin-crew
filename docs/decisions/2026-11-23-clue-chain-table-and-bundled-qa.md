- 레벨: L1 (방향은 진마씨 지시, 회차 수·진행 방식은 진마씨가 PM에게 맡김)
- 날짜: 2026-11-23
- 결정자: PM Noah
- 참여: 진마씨(방향), Kai·Luna·Theo(#802·#601 기존 의견)
- 출처: `#goblin-ceo` 진마씨 스테이지 2 방향 (2026-11-23) "땜질 대신 정답까지 가는 단서 사슬 전체를 한 번에 다시 봐 줘", "Mia 1회차로 판정하지 말고 2~3회차 묶음으로", "진행 방식과 회차 수는 PM이 사용량 보고 정해". #802 [코멘트](https://github.com/zaffrex/goblin-crew/issues/802#issuecomment-7091894145), #601

## 배경
`park_fountain`은 Mia 4회차 "뻔함" 뒤 5~8회차를 전부 못 풀었다. 막힌 자리는 회차마다 달랐고(6: 말풍선 잠금·높이·왜 오리, 7: 물 끈 뒤 비둘기, 8: 장대로 재킷 가는 길), 팀은 회차마다 그 자리 하나를 고치고 다음 회차를 돌렸다. 웃음(빗나감 15/21)은 들어왔지만 "알고 나면 당연한" 쪽이 안 채워지고 반복만 길어졌다. 8회차는 Mia가 도구 호출을 아끼려고 클릭 16번에서 멈춰 미완료다.

## 선택지
- A. **표 PR 1개 + 묶음 2~3회차 (데스크톱, 상한 30클릭)**: 빈칸을 한 번에 메우고 같은 빌드로 판정. 사용량은 묶음당 Mia 약 25분 / 표 PR이 커서 리뷰가 무거움
- B. 표 PR 1개 + 묶음 3회차 고정, 데스크톱·모바일 둘 다: 판정이 더 단단함 / 사용량이 약 2배, 리셋(11/26 04:00) 전 사용률 95%대 추정에 무리
- C. 지금처럼 회차마다 고침: 한 회차씩 빠름 / 진마씨가 멈추라고 한 방식

## 결정
**A.**
1. Kai는 `docs/design/screens/park_fountain.md`에 단서 사슬 표(단계 / 해야 할 생각 / 막히면 화면에서 무엇을 보고 알아채나 / 1~8회차 증거 / 메우는 법·새 칸 / "알고 나면 당연한가")를 넣고, **같은 PR에서** 빈칸을 메운다. 단계마다 알아챌 길을 둘 이상(다른 대상·캐릭터) 둔다. 단서가 첫 시도의 빗나감 전에 답을 말하지 않는지 표에 표시한다(뻔함 가드). 리뷰 Luna(그림 비용) + Theo(엔진).
2. 표 PR 머지·배포 전에는 Mia를 돌리지 않는다. 묶음 도중엔 아무것도 고치지 않는다.
3. 묶음 = 같은 빌드, 데스크톱, 최대 3회차. 1·2회차 판정이 같으면 3회차는 생략. 상한은 클릭 30번·15분(정답 길 3행동). 상한 전에 멈춘 회차는 세지 않고 다시 돌린다(묶음당 1번).
4. 회차 판정: 뻔함 = 클리어 + 정답 행동 예상 모두 "예" / 적당 = 상한 안 클리어 + 정답 행동 중 1개 이상 "아니오" / 어려움 = 상한까지 못 풂. 묶음은 다수결, 셋 다 다르면 적당 쪽으로 보고 막힌 자리를 표에 대조한다.
5. 묶음 "적당" + p0·p1 0 → 모바일 한 번 → 진마씨께 스테이지 2 요청. 아니면 Kai가 표 전체를 다시 보고 두 번째 묶음. **11/26 리셋 전 묶음은 최대 2번**, 두 번째도 적당이 아니면 진마씨께 선택지로 올린다.
6. 같은 표 형식을 `laundromat` 다시 보기에도 쓴다.

근거: 막힌 자리가 매번 다르다는 건 단계마다 알아챌 길이 하나뿐이었다는 뜻이다. 한 회차는 그 한 길을 지나갔는지만 보여 주고 운에 좌우된다. 상한 30은 7·8회차가 도구 호출 때문에 21·16번에서 멈춘 걸 보고 정했다. 상한에 실제로 닿아야 "힌트 없이 못 풂"이 확정된다.

## 반대 의견
가장 강한 반론: 표를 한 번에 메우면 단서가 늘어 4회차 "뻔함"으로 돌아갈 수 있다. 뻔함 가드 칸과 묶음 예상 줄 판정으로 다룬다. 상한을 40 → 30으로 줄이면 1~8회차와 숫자 비교가 어긋난다. 8회차까지 상한에 닿은 회차가 없어서 비교할 숫자가 원래 없다고 보고 받아들인다.

## 다시 볼 조건
- 두 번째 묶음도 "적당"이 아니면(진마씨께 선택지).
- Mia가 30클릭 상한도 못 채우고 멈추는 회차가 묶음에서 2번 나오면 QA 실행 설정(#516)을 Sam과 다시 본다.
- 사용률이 90%에 닿으면 묶음을 2회차로 고정한다.
