# 결정: #goblin-general을 게임 잡담·개발 외 아이디어 채널로 실제로 쓴다

- 레벨: L3(사장님)
- 날짜: 2026-11-15
- 결정자: 사장님
- 참여: PM Noah(운영 규칙 정리)
- 출처: `#goblin-ceo` 사장님 지시 (2026-11-15, 원문은 "배경" 인용), PR #29

## 배경
운영 매뉴얼에는 `#goblin-general` 용도가 "잡담, 아이디어, 공지"로 적혀 있었지만, 실제로는 자기소개와 공지만 올라왔다. 에이전트 실행 지시에 "할 일이 없으면 Slack에 쓰지 않는다(잡음 금지)"만 있어서 잡담이 생길 여지가 없었다. 사장님: "`goblin-general`에서는 만드는 게임에 대해서 간단한 잡담도 하게끔 해. 개발 이외의 아이디어들이 나올 수도 있잖아."

## 선택지
- A. 규칙 없이 "잡담해도 된다"만 공지 (간단 / 실행 지시가 그대로라 실제로는 안 생김)
- B. 운영 매뉴얼과 정기 실행 지시에 잡담 단계를 넣고, 멘션·결정·빈도 규칙을 붙인다 (실제로 생김 / 잡음·비용 관리 필요)

## 결정
**B.** 사장님 지시이고, 팀 운영 방식 변경이라 L3로 기록한다. 세부 규칙은 PM이 정했다 (`docs/team/operating-manual.md` "#goblin-general 잡담" 절).
- 주제: 만드는 게임 이야기. 캐릭터 성격·뒷이야기, 개그, 대사 아이디어, 이름 후보, 플레이어 반응 상상, 굿즈·트레일러 같은 개발 외 아이디어.
- 빈도: 정기 실행 때 떠오른 게 있을 때만. 역할당 하루 1회 정도. 억지로 쓰지 않는다.
- 멘션 금지: 잡담에는 `{@role}`을 쓰지 않는다. 멘션 1번 = 동료 실행 1번(비용)이다. 답은 각자 정기 실행 때 general 기록을 읽고 단다.
- 결정 금지: 잡담에서 정하지 않는다. 쓸 만한 아이디어는 PM이 주 1회(금요일 회고 전) 골라 백로그 이슈로 옮긴다.
- 말투: 근거·우려 규칙을 완화한다. 대신 맞장구만 하지 않고 하나를 보탠다 (yes-and).
- IP 가드레일은 잡담에도 똑같이 적용한다. 원작 캐릭터·퍼즐을 가져오자는 아이디어는 쓰지 않는다.

## 반대 의견
- PM 우려: 억지 잡담이 쌓이면 잡음이 되고 실행 비용(토큰)이 는다. 그래서 "멘션 금지 + 하루 1회 정도 + 할 말 있을 때만"으로 묶었다.

## 다시 볼 조건
- 1주 뒤(11/20 금 회고): 잡담이 하루 5개를 넘거나 아무도 안 쓰면 규칙을 조정한다. 주간 리포트에 분위기를 같이 보고한다.
- 잡담 때문에 개발 실행이 줄어드는 신호(같은 실행에서 산출물 없이 잡담만)가 보이면 빈도를 줄인다.
