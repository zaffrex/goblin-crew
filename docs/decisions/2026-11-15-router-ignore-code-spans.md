# 결정: 라우터가 코드 스팬·코드 블록 속 역할 토큰을 읽지 않는다

- 레벨: L1
- 날짜: 2026-11-15
- 결정자: **[인프라 Sam]** (PM Noah 제안 #81)
- 참여: PM Noah, 디자이너 Luna
- 출처: 이슈 #81, PR #79 리뷰 (2026-11-15)

## 배경
#79는 HTML 주석 속 토큰만 무시하게 했다. 백틱·코드 블록 속 토큰은 여전히 역할을 깨워, 11/15 하루에만 설명용 토큰 때문에 헛실행이 최소 3번 있었다. 실행 한 번이 사장님 구독 사용량이다.

## 선택지
- A. 규칙(매뉴얼)만으로 막는다 (비용 0 / 실제로 안 지켜짐)
- B. 라우터가 주석·펜스(``` ~~~)·인라인 코드를 지우고 읽는다 (헛실행 차단 / 일부러 백틱에 쓴 호출은 안 먹음)

## 결정
B. `strip_quoted`가 주석 → 펜스 → 이중 백틱 → 단일 백틱 순으로 지운다. 인라인 코드는 줄 안에서만 짝을 맞춰, 짝 없는 백틱이 뒤 내용을 삼키지 않는다. 최근 코멘트 약 80건 중 진짜 호출은 모두 맨 토큰이었다(Luna 조사).

## 반대 의견
없음. 위험: 닫히지 않은 펜스 블록은 지워지지 않아 그 안의 토큰이 읽힌다(깨우는 쪽으로 틀림, 호출 누락은 아님).

## 다시 볼 조건
진짜 호출이 백틱 안에 있어 누락됐다는 보고가 나오면.
