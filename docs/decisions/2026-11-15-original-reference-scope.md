# 결정: 원작은 "재미 참고"까지 허용, IP 리스크는 그대로 피한다

- 레벨: L3(사장님)
- 날짜: 2026-11-15
- 결정자: 사장님
- 참여: 사장님(지시), PM Noah(정리), 디자이너 Luna(재미 체크리스트 담당)
- 출처: #goblin-dev (2026-11-15) 사장님 스레드 "퍼즐 디자인을 정말로 재미있고 원작에 가까운 정도의 레벨을 원하는데", "재미 없을까봐 그게 걱정이야", "IP 리스크는 피하되 참고는 할수 있어", "아무튼 이런저런 검토해봐". 이슈 #71, PR #74

## 배경
사장님이 퍼즐이 재미없을까 봐 걱정하며, 원작을 분석하거나 플레이해서 설계할 수 있는지 물었다. Luna와 PM은 "직접 플레이·파일 분석은 못 하고, 퍼즐을 옮기면 IP 리스크"라고 답했다. 사장님은 IP 리스크는 피하되 웹 에뮬레이터 사이트 등에서 **참고는 해도 된다**고 답했다.
헌장의 IP 가드레일은 "레퍼런스는 장르 관습 수준에서만"이라고 적혀 있다. 그래서 "참고"가 어디까지인지 선을 문서로 정한다. IP에 관한 것이라 L3로 기록한다.

## 선택지
- A. 지금처럼 장르 관습만 참고. 가장 안전하다. 대신 사장님이 원하는 "원작급 재미"의 근거가 약하다.
- B. 원작에 대한 **공개 평가와 플레이 감상**을 참고 자료로 쓴다. 퍼즐 내용·해법·에셋은 옮기지 않는다. 재미/짜증 포인트를 실제 근거로 모을 수 있다.
- (기각) C. 원작 퍼즐을 분석해 비슷하게 옮긴다. 레벨 설계 복제라 IP 리스크다. 사장님도 "IP 리스크는 피하되"라고 했다.

## 결정
**B로 한다.** 원작은 "왜 재미있는가 / 어디서 짜증 나는가"를 배우는 참고 자료로 쓸 수 있다. 우리가 만드는 것은 전부 우리 것이다.

**해도 되는 것**
- 공개된 리뷰, 회고 기사, 위키의 게임 소개, 장르 분석 글을 읽는다
- 웹 에뮬레이터 사이트에서 사람이 플레이해 보고 감상을 남긴다 (현재 에이전트는 화면을 보며 조작할 수단이 없어 사장님만 가능)
- 거기서 얻은 것을 **패턴 수준**으로 적는다. 예: "정답과 무관한 클릭도 웃긴 반응이 있다", "게이지가 바닥나면 처음부터라 짜증 난다"

**안 되는 것 (IP 가드레일 그대로)**
- 공략에 나온 퍼즐 순서·해법·화면 구성을 옮기거나 비슷하게 만든다
- 원작의 스크린샷·스프라이트·음악·사운드를 저장소에 넣거나 내려받는다·추출한다·트레이싱한다
- 원작의 캐릭터 이름·생김새·대사·UI 외형을 닮게 만든다
- 문서에 원작의 특정 퍼즐을 "이 퍼즐처럼"이라고 적는다 (패턴 이름으로만 적는다)

**검토 방법**
1. Luna: 공개 리뷰·회고에서 재미 포인트와 짜증 포인트를 모아 재미 체크리스트(`docs/design/fun-checklist.md`)에 "망치는 법"으로 넣는다 (#71 남은 항목). 출처는 글 제목 수준으로만 적고, 퍼즐 해법은 적지 않는다.
2. 사장님이 직접 플레이해 보시면 "웃겼던 순간 / 짜증 났던 순간"을 한 줄씩 받아 같은 문서에 넣는다.
3. 화면 설계 PR 리뷰어는 "원작 퍼즐과 닮았는가"도 본다. 닮았다는 지적이 나오면 그 부분은 다시 설계한다.

## 반대 의견
- 가장 강한 반론(PM): 원작을 많이 볼수록 의도하지 않아도 퍼즐이 닮아 간다. → 참고 결과는 패턴 수준으로만 적고, 리뷰에서 닮음을 따로 검사한다. 원작을 더 직접 닮게 하는 방향은 여전히 별도 L3다 ([human-characters](2026-11-15-human-characters.md)의 레퍼런스 범위와 같다).
- 우려(PM): 리뷰·회고는 추억 보정으로 재미가 부풀려 적혀 있을 수 있다. → 최종 재미 판정은 문서가 아니라 M1(11/18) 사장님 플레이로 한다.
- 참고: 웹 에뮬레이터 사이트의 배포 권리는 우리가 확인할 수 없다. 우리는 거기서 아무것도 내려받거나 저장소로 옮기지 않으므로 우리 산출물의 IP 리스크는 늘지 않는다고 본다.

## 다시 볼 조건
- 리뷰에서 "원작 퍼즐과 닮았다"는 지적이 2건 이상 나오면 참고 방식을 다시 본다.
- M1 사장님 플레이에서 "재미없다"가 나오면 참고 범위보다 설계 방식부터 다시 본다.
- 정식 런칭(L3) 전에 IP 점검을 할 때 이 기록도 같이 본다.
