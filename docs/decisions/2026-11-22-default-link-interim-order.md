# 결정: 기본 배포 링크도 3화면을 잇되, `laundromat` 그림 전까지는 임시 순서로 둔다

- 레벨: L1
- 날짜: 2026-11-22
- 결정자: **[PM Noah]**
- 참여: 진마씨(질문), PM Noah
- 출처: `#goblin-meeting` M2 플래닝 스레드 2026-11-22 진마씨 "QA돌리는건 좋지만, 일단 한번 배포해봐. 나도 중간 확인해보게", "화면 1을 클리어하면 2로 넘어가는거 아니야?" / #766, #764, 회의록 `docs/meetings/2026-11-22-m2-planning.md`

## 배경
쿼리 없는 기본 배포 링크는 `magpie_nest` 하나에서 끝난다. 진마씨 재플레이 중 배포본이 바뀌지 않게 하려던 지킬 선이다(`2026-11-21-multi-screen-link-before-planning.md` 1번). 화면 연결은 `?playtest=1&order=` 뒤에서만 켜진다(#592). 진마씨가 중간본을 직접 이어서 해 보고 싶어 하셔서, 기본 링크도 이어지게 해야 한다(#766). 그런데 회의록의 최종 순서 첫 화면 `laundromat`은 아직 그림이 없는 회색 상자다(#764).

## 선택지
- A. 회의록 순서 그대로 `laundromat` → `magpie_nest` → `park_fountain` (최종과 같아 다시 안 바꿈 / 첫 화면이 회색 상자라 첫인상이 나쁘고 웃음이 안 보인다)
- B. 그림이 나올 때까지 임시 순서 `magpie_nest` → `park_fountain` → `laundromat`(회색) (진마씨가 아는 화면 1부터 시작, 회색 상자는 맨 끝 / 튜토리얼이 맨 뒤라 난이도 흐름은 최종과 다르다)
- C. `laundromat`을 빼고 `magpie_nest` → `park_fountain` 두 화면만 (회색 상자를 안 보여 준다 / 화면 3 퍼즐 확인을 못 한다)

## 결정
B. 결정적 근거: 진마씨가 이번에 보려는 건 "중간 확인"이고, 그림이 다 된 두 화면이 먼저 이어져야 확인할 게 생긴다. 회색 상자를 맨 끝에 두면 퍼즐도 보면서 첫인상은 해치지 않는다. 순서는 `order.json` 한 줄이라 되돌리기 쉽다.

지킬 선:
1. #766은 이 임시 순서로 머지한다. 화면 1 클리어 카드 글(`ui.clear`)은 다음 화면 안내가 있는 카드(`ui.next`)로 바뀌어도 된다. 진마씨가 바꿔 달라고 하신 동작이다.
2. `laundromat` 그림(#764)이 머지되면 같은 날 `order.json`을 회의록 순서로 바꾼다(Theo 또는 Luna, 데이터 한 줄 PR).
3. 세이브(#767)는 여기서 다루지 않는다. 시작 조건은 회의록 그대로다.

## 반대 의견
가장 강한 반론: 튜토리얼 화면이 맨 뒤라서 이 임시판으로는 "처음 하는 사람이 3화면을 따라오는가"를 볼 수 없다. 대응: 그건 최종 순서로 바꾼 뒤 Mia QA(#601 이후 회차)에서 본다. 임시판은 진마씨 중간 확인용이다.
