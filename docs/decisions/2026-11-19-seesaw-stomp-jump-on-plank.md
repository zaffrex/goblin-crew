# 결정: 묵직이 시소 쿵은 판 옆 땅 밟기가 아니라 판 끝에 뛰어올라 쿵 한다

- 레벨: L1 (연출 결정. 퍼즐 규칙·정답 순서·BFS는 그대로가 기본. 바뀌면 L2로 다시 본다)
- 날짜: 2026-11-19
- 결정자: **[PM Noah]**
- 참여: 진마씨(제안), PM(판단, 이슈 #414 본문), Luna·Theo(규격·구현 담당)
- 출처: `#goblin-ceo` 진마씨 (2026-11-19, 시소 올라서기 스레드) "묵직이가 쿵하고 땅을 발로차는게 아니라 시소에 점프해서 올라가면 반대쪽 시소의 사람이 반응하는게 더 재미잇지않아?", 이슈 #414, #397, PR #413, `docs/design/screens/magpie_nest.md` 1-5-2절·3절 10~15번

## 배경
정답 11번(`seesaw_launch_jjuk` ★)에서 묵직이는 판 옆 **바닥**을 밟고, 반대쪽 끝의 쭉이가 날아간다. 원인(무게)과 결과(튕김)가 화면에서 떨어져 있다. #397에서 깡충 올라서기가 들어간 뒤 더 어색해졌다. 묵직이가 걸어서 판 끝에 올라서도 아무 일이 없고, `stomp`를 누르면 도로 바닥으로 내려서서(#413) 땅을 찧는다.

## 선택지
- A. 지금 그대로 (작업 0 / 화면 1의 가장 큰 아하가 "왜 날아갔지?"로 읽힘. 진마씨 지적이 남음)
- B. 걷기로 올라서기만 해도 반대쪽이 날아간다 (가장 단순 / 묵직이 자리만 옮기려다 사고가 남. 걷기가 규칙을 일으키게 되어 데이터 모델·BFS가 바뀜 → L2)
- C. 쿵(`stomp`)은 판 끝에 높이 뛰어올라 쿵 → 반대쪽 반응(발사·실패). 걷기로 올라서기는 반대쪽이 살짝 들썩하며 놀라기만 한다 (규칙 그대로, 무게 → 튕김이 한 장면에 보임 / Luna 그림·Theo 엔진 작업이 다시 생김, 실패 장면 15번을 다시 그려야 함)

## 결정
**C.**
1. 쿵 → 시소 끝: 판 앞 바닥에서 높이 뛰어 그 끝에 쿵 내려앉는다 → U6 → 반대쪽 사람 반응(11·12번 발사, 13·14번 실패). 이미 그 끝에 서 있으면 제자리에서 뛰었다 쿵.
2. 걷기로 올라서기: 반대쪽 끝에 사람이 있으면 그 사람이 살짝 들썩하며 놀란다. 상태는 안 바뀐다. "무게로 저쪽이 뜬다"는 관찰 단서도 된다.
3. 15번(반대쪽 빈 판이 튀어 이마)·10번(끝에 다른 사람)은 새 동작에 맞게 Luna가 다시 설계한다.
4. 쿵 뒤 묵직이 위치(이슈 #414 Q1): PM 기본안은 바닥으로 내려섬(효과 `yard` 그대로). 판에 남기로 하면 퍼즐 상태가 바뀌므로 L2로 올린다.

결정적 근거: 무게로 반대쪽이 튕긴다는 인과가 그림 한 장으로 읽힌다. 화면 1의 가장 큰 아하 장면(10절 8번)이라 효과가 크다. 규칙은 그대로라 BFS·정답 길이에 영향이 없다.

## 반대 의견
가장 강한 반론: "#397을 방금 닫았는데 같은 장면을 또 고친다. M2(`park_fountain`)가 또 밀린다." → 진마씨가 직접 본 장면이고 정답의 핵심이라 먼저 한다([visual gate](2026-11-18-playtest-visual-gate.md) "아는 ❌를 남기고 요청하지 않는다"). 대신 범위를 시소 쿵 연출로 좁히고 다른 물건의 쿵 연출은 건드리지 않는다.

## 다시 볼 조건

- 정답 경로가 0.5초 넘게 늘면 높이 뛰기 ms부터 줄인다(걷기가 느리다는 지적과 겹치지 않게).
