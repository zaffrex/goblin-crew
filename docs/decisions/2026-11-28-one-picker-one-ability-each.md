# 결정: 물건을 집는 건 한 명(쭉이)만, 능력은 한 사람에 하나씩

- 레벨: L3(진마씨)
- 날짜: 2026-11-28
- 결정자: 진마씨 (누가 집는지는 PM 추천 ①, 진마씨 이견 없으면 확정)
- 참여: PM Noah, 퍼즐 Kai, 디자이너 Luna, FE Theo, BE Ben (설계 회의 1라운드)
- 출처: `#goblin-meeting` 설계 회의 "퍼즐 몸통을 물건 사슬로" 스레드 (2026-11-28). 진마씨 원문: "인벤토리의 이야기는 아니었어." → 장르 대표작 1편 구조 설명 → "한명만 잡기가 좋아 아니면 각각 능력은 하나씩". 이슈 #1031, ADR 초안 #1037

## 배경
진마씨가 세 판을 하고 "퍼즐 요소가 전혀 없다"고 했다(#1031). ADR-0018 개정 안건에서 PM은 "셋 다 손 1칸(물건 1개)"을 제안했다(ⓐ). ADR-0003이 "줍기/때리기/마법" 역할 분담을 원작과 비슷하다고 기각했고, 공통 동작(줍기·건네기·쓰기)은 셋 다 하도록 정해 두었기 때문이다. 진마씨는 이 ⓐ에 대해 "한 명만 집는 게 좋다, 능력은 한 사람에 하나씩"이라고 답했다.

## 선택지
- ⓐ 셋 다 손 1칸, 능력은 따로 하나씩 (ADR-0003 그대로 / 누가 들고 가는지가 퍼즐이 안 되고, 셋의 구분이 능력 한 번에만 남음) → 진마씨 기각
- ① 쭉이만 집고 든다 (장대 끝 집게가 원래 집는 도구라 그림·설정이 그대로 맞음 / 쭉이가 모든 사슬에 끼어 혼자 바빠질 수 있음)
- ② 삑삑이에게 줍기를 붙인다 (삑삑이 몫이 늘어남 / 삑삑이가 능력 두 개가 되어 "하나씩"에 어긋남)

## 결정
**①. 물건을 집고, 들고(한 번에 1개), 다른 곳에 쓰는 건 쭉이만 한다.** 다른 걸 들려면 지금 든 걸 내려놓는다. 인벤토리 줄은 만들지 않는다.

| 캐릭터 | 하나뿐인 능력 | 축 |
|---|---|---|
| 쭉이 `stretch` | 장대 집게로 집기·들기(1개)·내려놓기·쓰기. 멀리·높이 있는 것도 집는다 | 거리·손 |
| 묵직이 `stomp` | 쿵: 누르기·튕기기·깔고 앉기 | 무게 |
| 삑삑이 `squeak` | 삑: 부르기·쫓기·깨우기·소리 장치 켜기 | 소리 |

- ADR-0003의 "공통 동작(아이템 줍기·건네기·쓰기)은 셋 다" 줄은 이 기록으로 바뀐다. 걷기·보기는 셋 다 그대로다.
- 결정적 근거: 진마씨가 "누가 무엇을 할 수 있나"가 갈려야 퍼즐이 된다고 봤다. 한 명만 들 수 있으면 "누구를 어디로 보내 무엇을 들게 하나"가 사슬의 고리가 된다.
- IP: 원작의 셋 구성(줍기/때리기/마법)과 축이 다르다(집기/무게/소리). "한 명만 물건을 든다"는 장르 관습 수준의 규칙이고, 이름·그림·퍼즐·조합은 옮기지 않는다. 화면 설계 리뷰의 닮음 검사(`docs/design/research-original-screen-structure.md` 6절)는 그대로 한다. IP 판단은 L3 4번이라 진마씨 결정으로 기록한다.

## 반대 의견
- PM(ⓐ 제안자): ADR-0003이 역할 분담을 원작과 비슷하다고 기각했다. → 셋의 축을 거리·무게·소리로 둔 것은 그대로라 셋 구성이 겹치지 않는다고 보고 따른다(disagree and commit 아님, 근거 확인 후 동의).
- 가장 강한 반론: 쭉이가 모든 고리에 끼어 묵직이·삑삑이가 "가끔 누르는 버튼"이 된다. → ADR(#1037) 검사 줄로 다룬다: 쭉이 행동 비율 상한, 묵직이·삑삑이가 물건 상태를 바꾸는 고리가 화면마다 1개 이상.
