# 결정: 모든 결정을 GitHub에 문서로 남긴다

- 레벨: L3(사장님)
- 날짜: 2026-11-15
- 결정자: 사장님
- 참여: 사장님(요청), 셋업 담당 Claude(구현)
- 출처: 사장님 요청 "결정내용은 가급적이면 깃허브에 결정내용으로 해서 도큐먼트로 adr 처럼 기록할수 있도록 해줘"

## 배경
L1 결정은 Slack `#goblin-decisions`에 한 줄로만 남았다. Slack 기록은 검색과 추적이 어렵고, 왜 그렇게 정했는지가 남지 않는다.

## 선택지
- A. Slack 한 줄 기록 유지 (빠름 / 근거가 사라짐)
- B. 모든 결정을 ADR로 (철저함 / L1까지 2개 역할 리뷰가 붙어 느려짐)
- C. L1은 ADR 형식의 가벼운 결정 기록, L2는 ADR 유지 (근거가 남고 빠름 / 문서가 늘어남)

## 결정
C. `docs/decisions/`에 ADR과 같은 구조(배경, 선택지, 결정, 반대 의견, 다시 볼 조건)로 남긴다. 결정 기록만 바꾸는 PR은 리뷰 게이트를 자동 통과하므로 결정자가 바로 머지한다. Slack `#goblin-decisions`에는 문서 링크와 한 줄 요약을 올린다.

## 반대 의견
"문서 쓰는 시간 때문에 가벼운 결정이 느려진다." → 템플릿을 짧게 유지하고 리뷰를 생략해 비용을 줄였다.

## 다시 볼 조건
기록이 형식적으로 비어 있거나(선택지 1개, 근거 없음) 한 주에 20건이 넘으면 PM이 회고에서 다시 본다.
