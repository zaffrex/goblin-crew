# 결정: 진마씨께는 "스테이지 N"을 진마씨가 처음 해 보시는 순서로 부른다

- 레벨: L1 (진마씨 승인)
- 날짜: 2026-11-22
- 결정자: PM Noah 제안, 진마씨 승인("그렇게 해")
- 참여: 진마씨, PM Noah
- 출처: `#goblin-ceo` M2 플래닝 요청 스레드 (2026-11-22), 진마씨 "M1 에서 테스트한게 스테이지 1 이라고 생각했어. 그래서 새로운 다음 스테이지가 2 인줄 알았어" → "그렇게 해". 관련: #230, #601

## 배경
진마씨가 "M2에서는 스테이지 2도 진행하는 거지?"라고 물었다. PM이 답에 데모 안 순서(PM 추천안: `laundromat` → `magpie_nest` → `park_fountain`)까지 섞어 써서, "스테이지 2"가 어느 화면인지 헷갈리게 했다. 팀 안에서는 화면 id나 "화면 1/2"로 부르고, 진마씨는 해 본 순서대로 "스테이지"라고 부른다.

## 선택지
- A. 진마씨께는 진마씨가 처음 해 보시는 순서로 번호를 붙이고, 화면 이름을 늘 같이 쓴다 (진마씨 말과 같음 / 게임 안 순서와 어긋날 수 있음)
- B. 게임 안 순서로 번호를 붙인다 (게임과 같음 / 데모 순서가 아직 안 정해져 번호가 바뀔 수 있고, 진마씨가 해 본 기억과 안 맞음)

## 결정
A. 진마씨께 쓰는 글(Slack `#goblin-ceo`·DM, 플레이 요청, 주간 리포트)에서는:
- **스테이지 N = 진마씨가 처음 해 보시는 순서.** 지금 기준 스테이지 1 = `magpie_nest`, 스테이지 2 = `park_fountain`, 그다음 새 판은 `laundromat`(그림 전, M2 플래닝 뒤 제작).
- 번호 옆에 **화면 이름을 늘 같이** 쓴다. 예: "스테이지 2 `park_fountain`(공원 분수)".
- 데모 순서가 확정돼 게임 안 순서와 어긋나면, 플레이 요청 글에 "게임 안에서는 몇 번째 판"인지 한 줄로 따로 적는다.

팀 문서·이슈·코드는 지금처럼 **화면 id**로 부른다. 번호는 순서가 바뀌면 다 고쳐야 해서 쓰지 않는다.

## 반대 의견
가장 강한 반론: 진마씨께 쓰는 말과 팀 문서의 말이 달라 옮길 때 실수할 수 있다. 대응: 번호만 쓰지 않고 화면 id를 늘 같이 쓰게 해서, 번호가 틀려도 어느 화면인지는 남게 했다.

## 다시 볼 조건
- 데모 순서가 확정되고 진마씨가 처음부터 이어서 플레이하시게 되면: 게임 안 순서로 번호를 바꿀지 진마씨께 여쭌다.
- 진마씨가 번호 때문에 다시 헷갈리시면: 번호를 빼고 화면 이름만 쓴다.
