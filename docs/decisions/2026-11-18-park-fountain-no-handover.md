# 결정: `park_fountain` 출구를 "재킷을 집는 순간 클리어"로 바꾸고(3행동, M6 경고), #375를 A안 범위에서 뺀다

- 레벨: L1 (화면 하나의 범위 조정. ADR-0018 M6은 경고 항목이라 ADR 변경 아님)
- 날짜: 2026-11-18
- 결정자: **[PM Noah]**
- 참여: Luna(제안, PR #382 0-1절·13절 Q1), PM
- 출처: PR #382 (`park_fountain` 상세 설계 1차), 이슈 #380, #375, #311, `#goblin-dev` (2026-11-18) Luna 설계 공유

## 배경
매트릭스 5번 `park_fountain`(M2 A안 엔딩)의 출구는 "재킷을 아이템으로 받아 손님에게 건넨다"였다(정답 4행동). 그런데 아이템 칸은 #311에서 없어졌고, A안 3화면(`laundromat`, `magpie_nest`, `park_fountain`) 중 아이템을 쓰는 곳은 이 건네기 하나뿐이다. 건네기를 남기면 아이템 입력 UI를 새로 만들고, 집은 재킷을 화면에서 숨기는 형식(#375, ADR-0065 개정 + 코어 PR 가능성)도 필요하다.

## 선택지
- A. 건네기를 뺀다. 장대로 재킷을 집는 순간 클리어, 건네기는 클리어 컷에서 보여 준다 (아이템 UI·#375가 A안에서 빠짐 / 정답 3행동으로 ADR-0018 M6 일반 화면 4~10 아래, 경고)
- B. 건네기를 남긴다 (M6 충족 / 퍼즐이 아닌 한 행동 때문에 아이템 UI와 #375 코어 작업이 생김)
- C. 건네기를 빼고 PR #382 13절 Q2 줄다리기(재킷이 동상 손가락에 걸려 쿵 + 장대 협동)를 넣는다 (4행동, stretch 집기 연속 문제도 풀림 / 규칙 2개·유지 상태 1·애니 2칸 추가, 협동 입력 모델 확인 필요)

## 결정
**A.** 근거:
1. ADR-0018 52행: M6은 경고이고 "경고가 나면 PR에 이유를 적고 머지할 수 있다". ●/○ 배치, 유지 상태, C11 인과는 그대로라 ADR 변경이 아니다.
2. 건네기는 퍼즐이 아니라 의식이다(M5 분모에서도 원래 빠지는 행동). 그 한 행동 때문에 아이템 UI와 코어 변경을 만드는 건 "작고 완성된 게임" 원칙과 A안 일정 모두에 손해다.
3. C는 비용이 확실하고 이득은 아직 추정이다. 말로 하는 플레이 결과를 보고 정해도 늦지 않다(아래 다시 볼 조건).

따라서:
- #375(핫스팟 숨김 형식)는 A안 범위에서 닫는다. `rooftop_gap` 등 M2b 화면 설계에서 숨김이 필요해지면 다시 연다.
- `park_fountain` 화면 JSON PR에서 CI M6 경고가 뜨면 PR 본문에 이 기록을 링크한다.

## 반대 의견
가장 강한 반론(PR #382 13절 Q1, Luna 본인이 적은 것): "너무 쉬우면 엔딩이 싱겁다." PM 리뷰에서 하나를 더 짚었다: 주 아하의 KX2가 "중간"(테두리가 가장 큰 물건)이고 보조 아하 KX2가 "높다"라서, 아무거나 누르는 플레이어가 3번 만에 끝낼 수 있다. → 받아들이고, 10절 말로 하는 플레이에 "아무거나 누르는 사람이 몇 번 만에 끝나는지"를 넣어 판단 근거로 쓴다.

## 다시 볼 조건
- `park_fountain` 10절 말로 하는 플레이에서 "집기에 새 웃음이 없다(`magpie_nest`와 같은 맛)" 또는 "아무거나 눌러도 금방 끝난다"가 나오면: C(13절 Q2)로 바꿀지 다시 본다
- M2 진마씨 플레이에서 "엔딩이 금방 끝났다/싱겁다"가 나오면: 같은 판단
- A안 다른 화면이나 M2b 화면에 아이템 건네기가 다시 필요해지면: #375와 아이템 입력 UI를 함께 다시 연다
