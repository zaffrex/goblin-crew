## 배경
사장님이 게임 안 글을 전부 일본어로 정했다(B안, 한국어 없음). 캐릭터 이름과 동사 이름표, 게이지 이름은 대사 83줄과 HUD 전체에 반복해서 나오므로, Theo의 `ko.json` → `ja.json` 교체 PR 전에 고정해야 한다. 세부 표와 근거는 [`docs/design/ja-text.md` 1절](../design/ja-text.md).

## 선택지
- A. 한국어 이름을 소리 그대로 옮긴다(`チュギ`·`ムクチギ`·`ピクピギ`). 일본어 사용자에게 뜻이 없어 "이름 = 능력" 연결이 사라진다.
- B. 뜻을 직역한다. 이름이 길어지고 말장난이 사라진다.
- C. 한국어 이름을 지은 방식(능력의 소리·모양 + 부르기 쉬운 별명)을 일본어로 다시 한다. Luna 안.

## 결정
**C.**
| 무엇 | 일본어 |
|---|---|
| 쭉이 / 묵직이 / 삑삑이 | ノビー / ズッシー / プピ |
| 능력 이름표 뻗기 / 쿵 / 삑 | のばす / ドスン / プピッ |
| 손 / 보기 | さわる / みる |
| 올라서기 / 걷기 / 손 놓기 | のる / あるく / 手をはなす |
| 보송 게이지 | ふわふわゲージ |

- 결정적 근거: 이름과 능력 이름표가 같은 소리라(ノビー↔のばす, ズッシー↔ずっしり·ドスン, プピ↔プピッ) HUD만 보고도 누가 무엇을 하는지 이어진다. 판정 2에서 사장님이 HUD를 "전혀 모르겠다"고 했던 문제(#255)와 같은 방향이다.
- 이름 길이가 2·3·4자로 다른 건 그대로 둔다. 한국어도 2·3·3자였고, 이름이 들어가는 가장 긴 글(`ズッシーにかえる` 8자)도 여유가 있다.
- 표기 규칙: 동사는 히라가나, 소리 낱말은 가타카나. HUD 동사 이름표 3자 이하, 게이지 이름표 8자 이하, 말풍선은 지금 규칙 14자 × 2줄.

## 반대 의견
- `プピ`와 동사 `プピッ`이 ッ 하나 차이라 대사에서 이름인지 소리인지 순간 헷갈릴 수 있다(PM). 한국어 삑삑이/삑과 같은 구조라 막지 않았다.
- 원어민 검수가 없다(Luna, 상위 결정의 반대 의견과 같음). 재플레이 요청 때 어색한 줄을 알려 달라고 함께 부탁한다.
- IP: 버린 후보 `ピッピ`·`ドッスン`·`のび太`·`ノッポ`·`ピーコ`는 유명 작품·실존 인물과 겹친다. 남은 셋은 팀이 아는 범위에서 겹치는 작품이 없지만, 팀 지식 범위의 확인일 뿐이다. **정식 공개 전 상표·동명 조사(L3)에 세 이름을 함께 넣는다.**
