# 결정: 게임 안 글은 전부 일본어로 바꾼다 (한국어 없음)

- 레벨: L3(사장님)
- 날짜: 2026-11-17
- 결정자: 사장님
- 참여: 사장님(결정), PM Noah(선택지 제시·정리)
- 출처: #goblin-ceo (2026-11-17) 사장님 "게임 대사를 일본어로 해 줄 수 있어?" → PM 선택지 A/B/C → 사장님 답 "B". 이슈 #256

## 배경
사장님이 판정 2 1차 플레이(#257) 뒤 게임 대사를 일본어로 해 달라고 하셨다. 대사는 `content/text/ko.json` 한 파일(약 80줄)에 모여 있어 기술적으로는 작은 일이다. 다만 사람 이름·용어·말장난은 직역이 안 되고, 플레이어가 보는 언어가 바뀌는 일이라 사장님 판단으로 기록한다.

## 선택지
- A. 일본어 추가 + 언어 고르기(`?lang=ja`, 브라우저 언어). 한국어도 남김 (PM 추천). 단점: 글 파일 2개를 계속 같이 맞춰야 한다.
- B. 전부 일본어로 교체, 한국어 없음. 장점: 글 파일 1개, 언어 고르기 코드 없음. 단점: 팀 아무도 일본어 원어민이 아니라 어색한 문장을 팀 안에서 못 걸러낼 수 있다.
- C. M1을 닫은 뒤 시작.

## 결정
**B로 한다.** 사장님 결정.

범위 (PM 정리):
1. **플레이어가 보는 글만** 바꾼다: 말풍선 대사, HUD 이름표·설명, 아이템 칸·버튼 임시 글자, 안내 문구, 클리어·끝 카드, `<html lang>`(`ja`)과 페이지 제목.
2. 글 파일은 `content/text/ja.json` 하나만 둔다. `ko.json`은 같은 PR에서 지운다(두 파일이 어긋나는 걸 막는다, 원문은 git 기록에 남는다). 언어 고르기 코드는 만들지 않는다.
3. 사람 이름(쭉이·묵직이·삑삑이), '보송 게이지', 말장난은 직역하지 않고 일본어로 새로 짓는다(Luna 안, PM 승인 L1). IP 가드레일 그대로: 원작이나 다른 작품의 이름·대사를 가져오지 않는다.
4. **바꾸지 않는 것**: 팀 소통·문서·이슈·회의록은 한국어 그대로(`CLAUDE.md`). 개발자만 보는 콘솔·검사 메시지도 그대로. 코드 id(`jjuk` 등)도 그대로.
5. 글꼴은 지금처럼 `system-ui`(DOM 글자, ADR-0004 결정 3)라 일본어 글꼴을 따로 넣지 않는다. 말풍선 줄 길이 규칙만 일본어 기준으로 다시 맞춘다.

순서: #255(HUD 아이콘, 마지막 연결 PR #264) 다음에 #256. **판정 2 재플레이는 일본어판으로 요청한다.** 한국어판은 곧 없어질 화면이라 그걸로 다시 판정하면 사장님이 두 번 플레이하게 된다. 사장님이 그 전에 하고 싶으시면 한국어판 링크를 먼저 드린다.

## 반대 의견
PM은 A를 추천했다. 우려: 팀에 일본어 원어민이 없어 번역 품질을 팀 안에서 확신할 수 없다. 대응: 대사 하나하나를 직역하지 않고 장면 의도(설계 문서의 반응 표)에서 새로 쓰고, 재플레이 때 사장님께 어색한 줄을 알려 달라고 부탁한다. 결정은 그대로 따른다.

## 다시 볼 조건
- 사장님이 한국어판도 다시 필요하다고 하시면 A안 구조(언어 고르기)로 다시 연다.
- 외부 공개(클로즈 베타 등)로 일본어 원어민 플레이어가 생기면 원어민 검수를 그 공개 L3 결정 때 같이 올린다.
