## 2. 줄 길이 규칙 (일본어 기준)

- **말풍선: 지금 규칙 그대로 1줄 14자 × 2줄**(ADR-0018 R3, `validate.ts` `textFits`, 코드 포인트로 셈). 검사 코드는 바꾸지 않는다.
  - 근거: 한국어 14자에는 띄어쓰기(반각)가 섞여 실제 폭이 14자보다 좁았다. 일본어는 띄어쓰기가 없어 14자가 전부 전각이다. 16px 글자 14자 = 224px + 안쪽 여백 24px = 248px이고, 말풍선 최대 폭 `40vw`는 휴대폰 가로(폭 640px 이상)에서 256px 이상이라 자동 줄바꿈 없이 들어간다.
  - **목표는 12자 이하**, 14자는 한계다. 지금 초안의 가장 긴 줄은 11자(`あのカササギ、光る物を` 등)다.
- **줄은 문절(낱말 덩어리)에서 끊는다.** 낱말 중간에서 끊지 않는다.
- **줄 머리에 오면 안 되는 글자**(금칙): `、。！？…ー・〜` 작은 가나(`ぁぃぅぇぉっゃゅょゎゕゖ` `ァィゥェォッャュョヮヵヶ`) 닫는 괄호(`」』）】〕〉》］｝`). 두 번째 줄을 이 글자로 시작하지 않는다.
  - 작은 가나는 일본어 금칙 관습(JIS X 4051 줄 머리 금지)의 작은 가나를 다 넣었다. 비명(`うわぁ`·`ひぃ`)이 `うわ\nぁ`처럼 끊기면 낱말이 깨져 보인다. `・`(가운뎃점)·`〜`(늘임표)도 앞 글자에 붙는 글자라 같다. (PR #281 리뷰에서 늘림)
  - 예외 1: 말을 흐리는 `…`는 대사 머리에 쓸 수 있다(`…痛い。`).
  - 예외 2: **첫 줄이 `！？。`로 끝나고 둘째 줄이 새 말을 시작하면, 둘째 줄 머리 `…`를 허용한다.** "한 박자 쉬고 반전" 웃음 자리다(`うわああああ！\n…あれ？つかめた！`, `やった！\n…あれ？`). 문장 중간에서 끊긴 줄(앞 줄이 `！？。`로 끝나지 않음)의 머리 `…`는 여전히 금지다.
  - 한 문장을 둘째 줄로 이어 끊을 때(첫 줄이 `！？。`로 안 끝날 때)는 둘째 줄을 `…`로 시작하지 않는다. 그 `…`는 첫 줄 끝에 붙인다.
  - ノビー의 "`…`로 시작하지 않는다"(3절)는 **대사 첫머리** 규칙이다. 예외 2의 둘째 줄 `…`는 반전 틀이라 ノビー도 쓸 수 있다(`char.jjuk.look`).
  - **검사 원본은 `tests/content/ja-text-rules.test.ts`**(#280, PR #281)다. 금칙 글자와 예외 1·2, HUD 이름표·게이지·클리어 카드 길이를 거기서 검사한다. 이 절의 규칙을 바꾸면 테스트도 같은 PR에서 바꾼다. 예외 2에 해당하는 줄을 손으로 적은 목록은 테스트로 대체해 지웠다.
- 문장 부호는 전각(`！？、。`)을 쓴다. 말줄임은 `…` 1개(일본어 관습은 `……`지만 14자 안에서 1자를 아낀다).
- **HUD 동사 이름표: 3자 이하.** 휴대폰 가로에서 버튼 폭 약 46 CSS px, 11px 글자 + 좌우 여백 8px라 전각 3자(41px)까지 들어간다(ui-interaction 6-1-2 "번역 낱말을 짧게"). `手をはなす`(5자)는 대상 라벨에만 나오고 HUD 버튼 이름표가 아니라 괜찮다.
- **게이지 이름표: 8자 이하.** 게이지 폭 약 104 CSS px. `ふわふわゲージ`는 7자.
- 클리어 카드(28px): 1줄 12자 이하. `店のカギを取り返した！` 11자.
- 호버 설명·안내 문구(`ui.hud.*_hover`, `ui.intro`)는 말풍선이 아니라 14자 규칙 밖이다. 한 줄로 읽히게 20자 안팎으로 둔다.

## 3. 말투 (성격이 대사에 보이게, fun-checklist P9)

| 캐릭터 | 성격(ADR-0003) | 일본어 말투 | 예 |
|---|---|---|---|
| ノビー | 낙천·덜렁, 허세 | 밝은 반말. `…`로 시작하지 않는다(magpie_nest.md 말투 규칙 그대로) | `取った！\n店のカギだ！` |
| ズッシー | 과묵·느긋, 전직 씨름부 | `…`로 시작하는 아주 짧은 말. 명사·단정으로 끝낸다 | `…見た。` `…手より\nドスン。` |
| プピ | 막내, 수다·겁쟁이 | 공손한 `です・ます`, 선배를 `〜先輩`로 부른다. 혼잣말은 반말도 된다 | `高い所は\nノビー先輩の出番！` |

- 1인칭(`オレ`·`わたし` 등)은 쓰지 않는다. 성별을 정한 적이 없어서, 1인칭이 필요한 줄은 `自分`이나 주어 생략으로 푼다(`…自分のニワトリでした`).
- 자리(`@seesaw_left` 등)나 `self`가 화자인 줄(`launch`·`bump`·`wrong_way`·`spot_taken`·`let_go_jjuk`)은 누가 말해도 어색하지 않게 짧은 감탄으로 쓴다.
