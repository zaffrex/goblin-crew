## 1. 이름·용어 표 (PM 승인 대상)

## 2. 줄 길이 규칙 (일본어 기준)

- **말풍선: 지금 규칙 그대로 1줄 14자 × 2줄**(ADR-0018 R3, `validate.ts` `textFits`, 코드 포인트로 셈). 검사 코드는 바꾸지 않는다.
  - 근거: 한국어 14자에는 띄어쓰기(반각)가 섞여 실제 폭이 14자보다 좁았다. 일본어는 띄어쓰기가 없어 14자가 전부 전각이다. 16px 글자 14자 = 224px + 안쪽 여백 24px = 248px이고, 말풍선 최대 폭 `40vw`는 휴대폰 가로(폭 640px 이상)에서 256px 이상이라 자동 줄바꿈 없이 들어간다.
  - **목표는 12자 이하**, 14자는 한계다. 지금 초안의 가장 긴 줄은 11자(`あのカササギ、光る物を` 등)다.
- **줄은 문절(낱말 덩어리)에서 끊는다.** 낱말 중간에서 끊지 않는다.
- **줄 머리에 오면 안 되는 글자**(금칙): `、。！？…ー・〜` 작은 가나(`ぁぃぅぇぉっゃゅょゎゕゖ` `ァィゥェォッャュョヮヵヶ`) 닫는 괄호(`」』）】〕〉》］｝`). 두 번째 줄을 이 글자로 시작하지 않는다.
  - 작은 가나는 일본어 금칙 관습(JIS X 4051 줄 머리 금지)의 작은 가나를 다 넣었다. 비명(`うわぁ`·`ひぃ`)이 `うわ\nぁ`처럼 끊기면 낱말이 깨져 보인다. `・`(가운뎃점)·`〜`(늘임표)도 앞 글자에 붙는 글자라 같다. (PR #281 리뷰에서 늘림)
  - 예외 1: 말을 흐리는 `…`는 대사 머리에 쓸 수 있다(`…痛い。`).
  - 예외 2: **첫 줄이 `！？。`로 끝나고 둘째 줄이 새 말을 시작하면, 둘째 줄 머리 `…`를 허용한다.** "한 박자 쉬고 반전" 웃음 자리다(`うわああああ！\n…あれ？つかめた！`, `やった！\n…あれ？`). 문장 중간에서 끊긴 줄(앞 줄이 `！？。`로 끝나지 않음)의 머리 `…`는 여전히 금지다.
  - 한 문장을 둘째 줄로 이어 끊을 때(첫 줄이 `！？。`로 안 끝날 때)는 둘째 줄을 `…`로 시작하지 않는다. 그 `…`는 첫 줄 끝에 붙인다.
  - ノビー의 "`…`로 시작하지 않는다"(3절)는 **대사 첫머리** 규칙이다. 예외 2의 둘째 줄 `…`는 반전 틀이라 ノビー도 쓸 수 있다(`char.jjuk.look`).
  - **검사 원본은 `tests/content/ja-text-rules.test.ts`**(#280, PR #281)다. 금칙 글자와 예외 1·2, HUD 이름표·게이지·클리어 카드 길이를 거기서 검사한다. 이 절의 규칙을 바꾸면 테스트도 같은 PR에서 바꾼다. 예외 2에 해당하는 줄을 손으로 적은 목록은 테스트로 대체해 지웠다.
- 문장 부호는 전각(`！？、。`)을 쓴다. 말줄임은 `…` 1개(일본어 관습은 `……`지만 14자 안에서 1자를 아낀다).
- **HUD 동사 이름표: 3자 이하.** 휴대폰 가로에서 버튼 폭 약 46 CSS px, 11px 글자 + 좌우 여백 8px라 전각 3자(41px)까지 들어간다(ui-interaction 6-1-2 "번역 낱말을 짧게"). `手をはなす`(5자)는 대상 라벨에만 나오고 HUD 버튼 이름표가 아니라 괜찮다.
- **게이지 이름표: 8자 이하.** 게이지 폭 약 104 CSS px. `ふわふわゲージ`는 7자.
- 클리어 카드(28px): 1줄 12자 이하. `店のカギを取り返した！` 11자.
- 호버 설명·안내 문구(`ui.hud.*_hover`, `ui.intro`)는 말풍선이 아니라 14자 규칙 밖이다. 한 줄로 읽히게 20자 안팎으로 둔다.

## 3. 말투 (성격이 대사에 보이게, fun-checklist P9)

2026-11-18 진마씨 결정 A([기록](../decisions/2026-11-18-designer-ja-writer.md))로 대사는 **한국어 초안 없이 장면 의도에서 바로 일본어로** 쓴다. 모든 줄은 아래 말투표에 맞춘다. 표에 없는 말투가 필요하면 표부터 고친다.

| 캐릭터 | 성격(ADR-0003) | 1인칭 | 말끝·존댓말 | 아플 때·놀랄 때 | 남 부르기 | 예 |
|---|---|---|---|---|---|---|
| ノビー | 낙천·덜렁, 허세. **오사카벤**(3-3절, #367) | 안 씀(주어 생략) | 밝은 반말 오사카벤. `〜や！` `〜やん` `〜へん` `〜てもうた` `〜ちゃう？` `あかん`. 한 줄에 사투리 표지 1~2개. **`…`로 시작하지 않는다** | `いてっ` `いててっ` `いてて…`(두 번째부터 지친 소리) `うわっ` `おっとっと`(아플 때 소리는 사투리로 바꾸지 않는다, 3-3절). 막혔을 때 `あかん！` | 이름 그대로 `ズッシー` `プピ` | `取ったで！\n店のカギや！` |
| ズッシー | 과묵·느긋, 전직 씨름부 | 안 씀 | `…`로 시작하는 아주 짧은 말. `〜だ` `〜な`·동사 끝(`〜ないと` `〜てる`)을 섞는다. **명사로만 끝나는 줄(`…カギ。`)을 연달아 쓰지 않는다** | 소리를 안 낸다. `…効いた。` `…痛い。`(담담하게 받아들이는 게 웃음) | 이름 그대로, 짧게 | `…手より\nドスン。` |
| プピ | 막내, 수다·겁쟁이 | 필요하면 `自分` | 공손한 `です・ます`. 놀라서 튀어나온 말·혼잣말은 반말도 된다(`怒った！`) | `ひいっ` `ひゃっ` `うわわわ` + 사과(`ごめんなさーい！`) | `〜先輩`(`ノビー先輩`) | `高い所は\nノビー先輩の出番！` |
| 관리인 (`park_fountain`, 손님 NPC) | 졸린 할아버지. 30년째 "5분만" | 안 씀 | 짧은 반말 `〜だ` `〜か`. 노인 표지는 `いかん` 하나만. `わし`·`〜じゃ`·`〜のう` 같은 노인 역할어는 쓰지 않는다(가짜 사투리와 같은 이유로 과장해 보인다) | 벌떡 `はっ！` / 잠꼬대 `むにゃ…` | 부르지 않는다 | `はっ！いかん、\n掃除の時間だ！` |
| 손님 (`park_fountain`) | 내일 결혼하는 젊은 단골. 성별 미정 | 안 씀 | 젊은 존댓말 `です・ます`, 말끝을 줄인 `〜ます？`. 사투리 없음 | 감격·당황하면 말이 엉킨다(`あ、ありが…`) | 부르지 않는다 | `…これ、\nお願いできます？` |
| 자리 화자 | 누가 말할지 모름 | 안 씀 | 누가 말해도 되는 짧은 감탄·츳코미. 존댓말·반말이 드러나는 어미를 피한다 | `うわっ` | 부르지 않는다 | `使用中でーす！！` |

- 1인칭(`オレ`·`わたし` 등)은 쓰지 않는다. 성별을 정한 적이 없어서, 1인칭이 필요한 줄은 `自分`이나 주어 생략으로 푼다.
- 자리(`@seesaw_left` 등)나 `self`가 화자인 줄(`launch`·`bump`·`wrong_way`·`spot_taken`·`let_go_jjuk`)은 위 "자리 화자" 줄을 따른다. 기본 키는 중립으로 두고, 그 자리에 ノビー가 있을 때 표준어 어미가 드러나는 줄만 `<키>.jjuk` 변형을 둔다(3-3절).
- **아플 때 소리로 누가 맞았는지 갈린다.** 같은 감탄사를 세 사람이 섞어 쓰지 않는다(전에는 `いてっ`·`あいたっ`가 ノビー, `…痛い`가 ズッシー로 섞여 있었다).
- **한자**: 대사·카드·안내 글은 어른이 보통 쓰는 한자를 쓴다(`洗濯`·`誰か`·`伸ばす`). HUD 동사 이름표(`ui.verb.*`)만 히라가나(PM 결정, #359).

### 3-1. 실패 대사: 리액션 → 자책/츳코미 (#359)

진마씨 재플레이 피드백(`#goblin-ceo` 2026-11-18): "특히 뭔가 실패했을때" 대사가 어색했다. 원인은 실패 대사가 **원인을 설명**한 것(`向こう側、空っぽ`, `クチバシ、強烈`, `逆方向`)이다. 실패한 순간 사람은 설명하지 않고 먼저 아파하고, 그다음 자기나 남에게 한마디 한다.
- **1줄째 = 리액션**(아픔·놀람, 위 표의 감탄사). **2줄째 = 자책이나 츳코미.**
- 한 줄짜리는 리액션이 츳코미를 겸해도 된다(`使用中でーす！！`: 부딪힌 아픔을 "화장실 사용 중"으로 받아친다).
- **원인 설명문 금지.** 단서가 필요하면 혼잣말에 녹인다: `向こう側、空っぽ。`(설명) → `反対側、空いてる。`(맞고 나서 둘러본 혼잣말), `誰か乗ってたら。`(가정) → `誰か乗せないと。`(다짐).
- 두 번째부터(`*_again`)는 같은 리액션을 지치게(`いてっ！` → `いてて…`, `…効いた。` → `…また効いた。`) 하고 2줄째에 단서를 한 걸음 더 준다.
- `ui.faint`(게이지 0 컷)는 세 사람 공용이라 "자리 화자"처럼 쓴다. 실제로 일어나는 일(자리만 처음으로, 게이지 가득. ADR-0065 5절 6)과 맞아야 한다.

### 3-2. 대사 PR 소리 내 읽기 점검표

대사를 바꾸는 PR 본문에는 바꾼 줄마다 한 행(키·화자·의도(한국어)·새 줄)을 두고, 아래 1~4 중 **걸린 항목 번호만** 적는다(다 통과면 `—`). 걸린 줄은 고치거나 왜 두는지 적는다. 5는 테스트가 줄마다 보므로 PR당 "통과" 한 줄로 쓴다.
1. 소리 내 읽어 한 호흡에 읽히나 (명사로 뚝 끊겨 자막처럼 읽히지 않나)
2. 한국어 어순·말투(직역 냄새)가 남지 않았나
3. 어른이 쓰는 한자를 히라가나로 풀지 않았나 (HUD 동사 이름표 예외)
4. 말투표와 맞나, 그 상황에서 그 사람이 정말 그렇게 말하나. 유명 작품 대사·유행어를 그대로 가져오지 않았나(IP 가드레일)
5. 줄 길이·금칙: `npm test`(`ja-text-rules`, `textFits`)

### 3-3. ノビー 오사카벤 규칙 (#367)

진마씨 결정 "한사람은 오사카벤"(`#goblin-ceo` 2026-11-18, [기록](../decisions/2026-11-18-one-character-osaka-ben.md)). 대상은 ノビー. 가장 큰 리스크는 원어민이 아닌 사람이 쓴 사투리가 **가짜 사투리(エセ関西弁)** 로 읽히는 것이라, 일상에서 가장 많이 쓰는 기본형만 쓰고 과장하지 않는다.

| 쓴다 | 표준어 | 예 |
|---|---|---|
| `〜や` `〜やな` | `〜だ` `〜だな` | `店のカギや！` `まずカササギやな…` |
| `〜やん` `〜やん？` | `〜じゃん` `〜じゃない？`(확인·발견) | `ふかふかやん！` `届いてるやん？` |
| `〜へん` | `〜ない` | `届かへん` `見えへん` `くれへん？` |
| `〜てもうた` | `〜ちゃった` | `また伸ばしてもうた` |
| `ちゃう` `〜ちゃう？` `ちゃうんかい` | `違う` `〜じゃない？` | `担当ちゃう？` `…ちゃうんかい！`(혼자 받아치기) |
| `〜で`(알려 주기) | `〜よ` | `重さがいるで` `使用中やでー！！` |
| `〜やったら` `〜やと` | `〜なら` `〜じゃ` | `床やったらもう` `サオやと軽いか` |
| `あかん` `ええ` `よう` `おる` `めっちゃ` `なんや` | `だめ` `いい` `よく` `いる` `すごく` `なんだ` | `あかん！` `伸ばせたらええのに…` `先客おるやん。` |
| `〜ん？`(물음) | `〜の？` | `誰が止めるん？`(#380) |
| `よっしゃ`(감탄) | `よし` | `よっしゃ取った！`(#380). 표지 1개로 센다 |

- **피한다**: `なんでやねん`(쓰더라도 화면 전체 1회, 지금은 0회), 상인 고정관념 말투(`おおきに` `〜でんがな` `〜まんねん` `もうかりまっか`), 1인칭 `ワイ`·`ウチ`(3절 1인칭 금지 그대로), 유명 개그맨·작품의 유행어
- **한 줄에 사투리 표지 1~2개.** 모든 낱말을 바꾸지 않는다. `じゃ`(`手じゃ`·`下からじゃ`)·`のに`처럼 오사카 사람도 그대로 쓰는 말은 굳이 바꾸지 않는다
- **아플 때 소리는 그대로**(`いてっ` `いててっ` `いてて…`). 3절 "아플 때 소리로 누가 맞았는지 갈린다"를 지키려고 바꾸지 않는다
- **자리·`self` 화자 줄**: 기본 키는 중립 그대로 두고, ノビー가 그 자리에 있을 때 표준어 어미(`〜ちゃった` `〜じゃなーい` `〜がいる` `〜でーす`)가 드러나는 줄만 `.jjuk` 변형을 둔다(`sayText`가 화자 변형을 먼저 고른다). 어미가 중립인 줄(`launch`의 `…あれ？つかめた！`)은 변형을 두지 않는다
- **말풍선 폭을 늘리지 않는다**: 고친 줄의 가장 긴 줄은 원래 줄 이하이거나 10자 이하(`wrong_way_again.jjuk`만 원래와 같은 11자). 말풍선 배치(#329·#356·#358)가 바뀌지 않게 한다
- 다른 두 사람(ズッシー·プピ)은 표준어 그대로. プピ·ズッシー가 ノビー를 부르는 말도 그대로
- 원어민 검수가 없으니, 진마씨·플레이어가 "사투리가 어색하다"고 한 줄은 이유를 따지지 않고 먼저 고치고, 걸린 표현은 위 표에서 뺀다
