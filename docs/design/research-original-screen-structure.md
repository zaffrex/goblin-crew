## IP 선 (이 문서가 지킨 것)

- 공략 글을 **읽고 구조만 셌다.** 화면마다 적은 것은 숫자, 그래프 모양, 고리 종류, 그리고 "왜 되는지"를 판정하려고 쓴 짧은 요약 한 줄이다. 공략 문장은 옮기지 않았다.
- 원작을 내려받거나 플레이하지 않았다. 스크린샷·그림도 보지 않았고 저장소에 넣지 않았다.
- 6절 "닮음 검사 목록"은 **우리 설계에 쓰면 안 되는** 원작 조합이다. 화면 설계 PR 리뷰어가 이 목록으로 닮음을 본다.
- 이 문서에는 우리 퍼즐 예시를 새로 넣지 않았다. 다리는 "조사 → 숫자 원칙(ADR) → 우리 세계관으로 새 설계"다.

## 1. 셈 방법

공략은 "푸는 순서"라서 의존을 거꾸로 복원했다. 화면마다 아래 순서로 셌다.

1. 공략 두 개를 나란히 놓고 **상태를 바꾸는 단계**만 남긴다. 걷기, 캐릭터 바꾸기, 대화만 하는 단계, 같은 행동 반복은 뺀다. 남은 수가 **행동**이다.
2. 단계마다 종류를 붙인다.
   - **줍기**: 화면의 물건이 손에 들린다.
   - **변화**: 물건 **하나**의 형태·상태가 바뀌고, 바뀐 물건이 다음 고리에 쓰인다(마법, 장치, 불, 시간 등 무엇으로 바뀌든). 손에 든 물건이 아니라 화면의 장치만 바뀌는 것(가지가 발판이 됨)은 넣지 않았다.
   - **결합**: 물건 **둘 이상**이 합쳐 하나의 결과가 된다. 손에서 합치든, 장치·NPC 안에 넣어 합치든 같이 센다(예: 재료 셋을 섞는 기계, 두 물건을 받아 새 물건을 만들어 주는 NPC).
   - **사용**: 물건 하나를 핫스팟·NPC에 쓰거나 줘서 다른 상태를 연다.
   - **능력**: 그 캐릭터만 할 수 있는 행동이 필요한 단계(1편은 마법·치기·오르기. 줍기·들기는 넣지 않음). 2편처럼 능력 차이가 작은 판은 **둘이 같이**(한 사람이 붙잡고 있는 동안 다른 사람이 하는 단계)를 센다.
3. **의존 그래프**: 단계마다 "이 단계가 되려면 앞의 어느 단계가 끝나 있어야 하나"를 공략 문장(…하면 ~가 떨어진다/열린다)으로 이었다. 깊이 = 가장 긴 의존 사슬의 단계 수, 폭 = 같은 때에 순서 상관없이 할 수 있는 갈래의 최대 수.
4. **"왜" 한 문장**: 정답 길의 핵심 고리를 "A는 ~하고 B는 ~하니 ~"로 쓸 수 있으면 **예**, 고리 일부만 되면 **부분**, 안 되면 **아니오**.
5. **실패 반응 수**: 공략은 틀린 시도를 적지 않는다. 원작은 **셀 수 없음**으로 두었다. 우리 판만 JSON에서 셌다(효과 없는 규칙 + `fallbacks` 중 `look` 아닌 칸).

**표시**: 두 출처의 순서·단계가 맞으면 **확인**, 순서가 엇갈려 깊이·폭을 내가 골라야 했으면 **추정**. 추정 화면은 5절 기준을 정할 때 범위만 보고 중앙값 계산에는 넣되 따로 적었다.

## 4. 숫자로 본 차이

원작 12화면(O1~O12) 기준. 추정 화면(O2·O3·O8·O10)을 빼고 다시 센 값을 괄호에 적었다.

| 잣대 | 원작 | 우리 3판 | 차이 |
|---|---|---|---|
| 행동 | 5~30, 중앙 12 (추정 빼면 5~15, 중앙 11.5) | 3~4 | 약 3~4배 |
| 의존 깊이 | 4~10, 중앙 7 (추정 빼면 중앙 6.5) | 2~3 | 2~3배 |
| 폭 ≥2인 화면 | 10/12 (추정 빼면 6/8) | 2/3 | 비슷. **폭은 문제가 아니다** |
| 물건 **사용** ≥1 | 12/12, 중앙 4.5 | 0/3 | 가장 큰 차이 |
| 변화 ≥1 | 9/12 | 0/3 | |
| 결합 ≥1 | 8/12 | 0/3 | |
| 변화 ≥1 **그리고** 결합 ≥1 | 5/12 (O4·O8·O9·O10·O11) | 0/3 | 원작도 절반 아래 |
| 능력 단계 / 행동 (1편 O1~O5) | 17~45% | 100% | 원작에선 능력이 고리 일부만 연다 |
| 앞 화면에서 들고 온 물건이 있음 | 7/12 | 0/3 | 원작 화면은 물건을 주고받는다 |
| 한 번 보여 준 변화 규칙을 두 번 이상 씀 | 5/12 (O2·O4·O9·O11·O12) | 0/3 | |
| "왜"가 **예** | 6/12, 부분 5, 아니오 1 | 0/3 예 | 원작도 다 설명되지는 않는다 |
| 한 번에 드는 물건 | 1편 1개(한 사람만), 2편 사람마다 1개(추정) | 0개 | 원작은 무차별 대입을 "손 1개"로 막는다 |

읽은 것:

1. **진짜 차이는 "물건이 간선인 고리"다.** 원작은 12화면 전부 물건을 줍고 쓰며(중앙 4.5번), 우리는 0이다. 깊이 차이(7 대 2~3)도 대부분 여기서 나온다. 원작 사슬의 한 마디는 보통 "얻기 → 바꾸기/합치기 → 쓰기"라 마디마다 행동이 2~3개다. 우리는 마디 하나가 버튼 하나다.
2. **진마씨 문장 모양(변화 → 결합 → 사용)은 원작에서도 화면의 절반 아래(5/12)다.** 다만 그 다섯 화면이 각 편의 중반·후반 중심 화면이다(1편 동굴, 2편 성·실험실, 3편 시골·실험실). 그러니 "모든 화면 필수"보다 "일반 화면 필수, 튜토리얼 예외"가 원작 분포에 맞다.
3. **원작도 "왜"를 다 설명하지 않는다.** 1편 마법은 일부러 결과를 예측하기 어렵게 만든 능력이고(O1 아니오), 그 빈칸을 **싼 시험**(눌러 보면 바로 바뀐 모습이 보인다)으로 메운다. 진마씨 ③은 우리에게 그보다 높은 기준을 요구한 것이다. 우리는 마법 같은 "규칙 없는 변화" 능력이 없으니(쿵·장대·소리는 물리) 오히려 "예"를 맞추기 쉬운 쪽이다.
4. **"알고 나면 당연한"을 원작은 규칙 재사용으로 만든다.** O4(불 앞에 두면 구워짐 ×2), O9(규칙을 다음 화면에서 다시), O11(같은 도구로 처방 셋), O12(같은 거울을 여러 번)에서 처음 한 번은 놀람, 두 번째는 플레이어가 **앞으로 추론**한다. 우리 판은 화면마다 버릇을 새로 만들고 한 번만 써서(1차 3-2절 1번) 두 번째 기회가 없었다.
5. **3편의 연금술 실험실(O11)이 진마씨 "연금술사적 어프로치"에 가장 가까운 구조다.** 재료마다 먼저 변화(굽기·삶기·빻기)를 거치고, 셋을 한 장치에서 결합하고, 결과물(약)을 화면 밖 여러 곳에 쓴다. 처방은 화면 안 책에 있다(단서가 화면 안에). 깊이 4, 폭 3인 "퍼졌다 모이기"다. 비교작 D1도 같은 모양(재료 셋, 각각 다른 길 → 한 점에서 조립)이다.
6. **우리는 반응에 쓰고 사슬에 안 썼다.** 우리 판은 정답 행동 하나당 실패 반응 5~12개다. 원작 수는 셀 수 없었지만, 원작 화면은 정답 행동 자체가 10개 안팎이라 같은 반응 예산(ADR-0422)이면 반응이 사슬 쪽 결과 칸에 더 붙는 구조다.

| P1 변화 ≥1, 결합 ≥1 | 원작 5/12. 중심 화면에서만 다 있음 | **유지**(진마씨 문장이 기준이라서). 단 튜토리얼 화면(`magpie_nest`류)은 "물건 사용 ≥1"만. 결합에 "장치·NPC 안에서 합치기"를 넣는다(원작 결합 12번 중 8번이 이 모양, 추정 포함) |

| P2 "왜" 한 문장 | 원작 예 6/12 | **유지, 원작보다 높게.** 진마씨 ③ 때문. 마지막 고리(클리어 직전)는 반드시 예 |

| P5 깊이 ≥3, 폭 ≥2, 5~8행동 | 원작 깊이 중앙 7, 행동 중앙 12. 폭은 이미 비슷 | **깊이 ≥5, 행동 8~12**(원작 중앙 아래쪽. 첫 적용은 한 화면이라 상한을 원작보다 낮게). 폭 ≥2 유지 |
| P6 틀린 조합이 성질을 가르침 | 공략으로는 셀 수 없음 | 유지(근거는 1차 글) |
| P7 동시에 드는 물건 ≤3, 줍는 물건 ≤4 | 원작은 손 1개(1편). 줍기는 1~9 | **동시에 드는 물건 ≤2**(공용, Theo 리뷰 #1033: 인벤토리는 이미 공용), 줍는 물건 ≤5 |

## 6. 닮음 검사 목록 (우리 설계에 쓰지 않는다)

화면 설계 PR 리뷰어가 이 목록과 겹치는지 본다. 모양(변화 → 결합 → 사용)은 장르 관습이라 써도 되고, **아래의 구체 조합**은 쓰지 않는다.

- 마법으로 나뭇가지·깃털·벌레 같은 것을 도구로 바꾸는 조합(O1·O3)
- 구멍을 막아 동물이 나올 구멍을 정하고 자루로 잡는 조합(O2)
- 냄새나는 것에 냄새 제거제를 뿌려 불 뿜는 상대 앞에 두는 조합, 불로 물건을 데워 다음 화면 장치에 쓰는 조합(O4)
- 웃겨서 울린 눈물을 그릇에 받는 조합(O5)
- 주전자 김으로 붙은 종이를 떼는 조합, 뻐꾸기시계를 감아 나온 새를 맞히는 조합(O6)
- 말랑한 것으로 열쇠 본을 떠서 대장장이가 열쇠를 만드는 조합(O8)
- 마법 물에 적신 면에 그림을 그려 문을 만드는 조합(O9)
- 매운 가루로 재채기를 시키는 조합, 숟가락 + 돌 지레로 날리는 조합(O10)
- 재료를 굽고·삶고·빻아 혼합기에 넣어 약을 만드는 실험실 화면 자체(O11). "재료를 변화시켜 합친다"는 모양만 쓰고, 실험실·약·처방책 구성은 쓰지 않는다
- 시간·뚱뚱·홀쭉 거울로 한 동물을 키우고 줄이는 조합(O12)
- 술을 오래 두어 식초를 만드는 조합(D1)

## 7. 한계

- 공략 두 개가 같은 원본을 보고 썼을 수 있다. 서로 다른 사이트이고 단계 순서가 몇 군데 달라서(O2·O3) 독립으로 봤지만 확인은 못 했다.
- 2·3편은 화면이 아니라 화면 몇 개의 묶음(구간)으로 셌다. 묶음을 어디서 끊느냐에 따라 행동 수가 크게 바뀐다(O8·O10을 추정으로 둔 이유). 깊이·폭은 묶음 경계에 덜 민감하다.
- 실패 반응 수는 원작에서 못 셌다. 원작이 반응을 몇 개 두었는지가 반응 예산(ADR-0422, Luna)에는 중요한 숫자인데 공략으로는 알 수 없다.
- 직접 플레이하지 않았다. "왜" 판정은 공략 문장에서 인과가 보이는지로 했고, 실제 화면에 단서가 얼마나 보이는지는 판정하지 못했다.
