# 화면 글·상자 세부 체크리스트 (#330)

작성: 디자이너 Luna · 2026-11-18 · 결정 기록: [playtest-visual-gate](../decisions/2026-11-18-playtest-visual-gate.md)

진마씨께 플레이를 부탁하기 **전에** PM이 이 표로 스크린샷을 확인한다. replay·frames·smoke는 "동작"을 본다. 이 문서는 "**보이는 모양**"을 본다.
UI를 바꾸는 PR은 바뀐 요소의 줄만 다시 찍어 PR에 붙인다(권장).

## 1. 찍는 화면 크기 (4개)

| 이름 | 뷰포트 | dpr | CSS 배율 | 왜 |
|---|---|---|---|---|
| D1 | 1280×720 | 1 | 2 | 기본 데스크톱 |
| D4 | 1920×1080 | 1 | 4 | 큰 화면. 고정 px 글자가 작아 보이는 곳 (#329에서 진마씨 화면) |
| M3 | 844×390 | 3 | 1.333 | 보통 휴대폰 가로 |
| M1 | 667×375 | 2 | **1.0** | 가장 작은 실제 배율(iPhone SE급). 넘침·잘림이 먼저 나오는 곳 |

- 글꼴: **Noto Sans CJK**(`sudo apt-get install fonts-noto-cjk`). 글꼴 없이 찍은 스크린샷은 폭이 달라서 판정에 쓰지 않는다.
- Safari(Hiragino)·삼성 글꼴은 실기기에서 따로 본다(지금은 미확인, 4절).

## 2. 판정 항목 (요소마다 전부)

| ID | 항목 | 실패 예 |
|---|---|---|
| C-1 | **잘림 없음**: 글 끝까지, 상자 테두리까지 보인다. 스크롤이 생기지 않는다 | 카드 아랫줄이 스크롤 아래로 숨음 |
| C-2 | **의도한 줄바꿈만**: 작가 줄바꿈(`\n`)에서만 접힌다. 낱말 중간에서 접히지 않는다 | `高い所 / に届く` |
| C-3 | **게임 화면 안**: 상자가 게임 캔버스 밖(검은 여백)으로 나가거나 걸치지 않는다 | 상자 반이 여백에 걸침 |
| C-4 | **겹침 없음**: 다른 DOM 글, 얼굴 칸, 게이지, **단서가 되는 물건**(까치, 둥지, 고리, 시소)을 덮지 않는다 | 말풍선이 까치를 덮음 |
| C-5 | **크기 위계**: 글자가 배율을 따른다. 같은 화면에서 말풍선 ≥ 카드 ≥ 라벨·이름표 순으로 읽힌다. 1.0배에서 11px 이상 | 4배에서 14px 고정 |
| C-6 | **연결이 보임**: 말풍선은 화자를, 라벨은 대상을, 이름표는 얼굴을 가리킨다고 읽힌다 | 꼬리가 다른 사람을 가리킴 |
| C-7 | **대비**: 바탕 위 글자가 읽힌다(하늘·벽돌·잔디 위 각각) | 반투명 바탕 없이 하늘 위 흰 글자 |
| C-8 | **조작 안내가 보임**: 다음에 무엇을 누르는지가 화면에 있다 | `タップではじめる`가 안 보임 |
